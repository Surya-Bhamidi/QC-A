🎓 University Endsem Presentation: Top Examiner Questions
Q1: Why did you use the Quantum SWAP Test instead of a Variational Quantum Circuit (VQC)? ▾
Answer: Standard Variational Quantum Circuits (VQCs) rely on deep layers of parameterized gates that are susceptible to Barren Plateaus (exponentially vanishing gradients) as qubit counts grow. In contrast, the SWAP test is a fixed, non-parametric $O(1)$-depth circuit that computes the Hilbert space inner product (fidelity) $|\langle \psi_q | \phi_k \rangle|^2$ directly. This provides a guaranteed, stable gradient path back to classical projection matrices while serving as the exact quantum counterpart to classical dot-product attention.
Q2: What is the physical role of the Ancilla Qubit in the circuit? ▾
Answer: The ancilla qubit acts as a quantum interferometer. Placing it in superposition with a Hadamard gate allows it to control the pairwise swapping between Query and Key registers. The second Hadamard gate translates the relative quantum phase difference into measurable computational basis probabilities $P(|0\rangle)$ and $P(|1\rangle)$. Measuring Pauli-$Z$ on the ancilla yields $\langle Z_a \rangle = P(|0\rangle) - P(|1\rangle) = |\langle \psi_q | \phi_k \rangle|^2$, directly giving the attention weight.
Q3: Why did you choose Angle Embedding ($RY$ rotations)? ▾
Answer: Angle embedding encodes $d$ continuous features into $d$ qubits using single-qubit rotations $RY(\theta_i)$ with constant $O(1)$ circuit depth, avoiding noisy multi-qubit entangling gates for state preparation. Moreover, rotation angles $\theta_i = \frac{\pi}{2}(\tanh(x_i) + 1) \in [0, \pi]$ are smoothly differentiable and allow exact analytical backpropagation via PyTorch autograd.
Q4: Why does QViT use fewer trainable parameters than Classical ViT? ▾
Answer: In Classical ViT, the Query ($W_Q$) and Key ($W_K$) projection matrices map from $D \to D$ ($32 \times 32 = 1,024$ weights each per block). In QViT, they project from $D$ down to the compact quantum register size $n_{\text{qubits}}$ ($32 \times 4 = 128$ weights each). This achieves an 87.5% reduction in attention projection parameters, yielding an overall 2.72% reduction across the complete model while maintaining higher accuracy.
Q5: How does the Quantum model achieve higher accuracy? ▾
Answer: While classical attention computes inner products in a flat Euclidean space, $n$ qubits operate in a $2^n$-dimensional complex Hilbert space. The SWAP test computes state overlap directly in this space, acting like an implicit Quantum Kernel Trick (RKHS). Coupled with 2-head Multi-Head Quantum Attention and temperature calibration, the model learns sharper, more localized attention over pulmonary opacities.
Q6: What is the primary novelty and academic contribution of this work? ▾
Answer: We demonstrate the first end-to-end differentiable hybrid Vision Transformer that completely replaces dot-product attention with a non-parametric Quantum SWAP Test kernel for real medical diagnosis. We empirically prove that it beats the classical baseline (83.81% vs 81.41% test accuracy) with fewer parameters, achieves $>91.4\%$ validation accuracy, and demonstrates quantified NISQ noise resilience up to 10% depolarizing error rates.
