# Preserved failures and resolutions

* Initial public calibration download was blocked by the network sandbox. The first automatic approval review timed out; its explicitly permitted retry succeeded. No unavailable physical access is inferred from this.
* Second test-suite run: 10 tests, 1 cleanup error. `test_exact_resume_and_complete_test` passed its exact-weight and complete-test assertions but left an `np.load` NPZ handle open, preventing Windows temporary-directory cleanup. Fixed by closing the NPZ handle. This did not change the experiment computation.
* The proposed combined allocator is not an empirical win at the prespecified 64-shot attention-output endpoint. This is a research finding, not a software exception; all configurations and results remain available.
* The existing Python environment emits a requests dependency-version warning and PennyLane 0.45.1 emits tape-expansion deprecations. Circuit tests pass on the pinned installed version. Migration to future PennyLane must rerun those tests.
* Secondary suite and ablation runner encountered transient Windows `WinError 5` during atomic replacement of a checkpoint and the index JSON in the OneDrive workspace. Added bounded retries without changing model computation, preserved the old checkpoints, and resumed both runners. Resume events record the revised source hashes; original run snapshots remain intact.
* Tectonic initially attempted to write outside the workspace and then could not download packages in the network sandbox. A workspace cache and approved public-package download resolved compilation. Fontconfig emits a configuration warning; compiled PDFs were rendered and visually inspected. Minor underfull text boxes do not clip content.
* The workspace-only PDF renderer installed by the approved pip command inherited temporary-directory permissions. Sandbox import exposed an empty namespace; approved local rendering outside that sandbox restriction succeeded. This utility is separate from the experiment environment and does not affect saved model results.
* The October 2 joint selective-mitigation method loses to strong baselines at its frozen primary endpoint. All 2,400 test configurations are retained; the core optimizer was not retuned after seeing test results.
* The follow-up evidence checker first passed all 2,400 prediction/budget ledgers, then failed its 1e-9 circuit-equivalence threshold because PennyLane received float32 saved angles while the factorized simulator promotes gates to float64. The first historical-noise discrepancy was 1.89e-8; matching float64 inputs reduced it to 1.16e-13 (stress: 2.10e-13). Only the verifier's input precision was corrected; frozen experiment code and saved results were unchanged.
* The follow-up verifier then completed all numerical checks but could not serialize a NumPy boolean in its JSON summary. Converting the diagnostic z-score to a Python float fixed report serialization. This changed neither simulations nor experimental results.
* The hybrid accuracy process was interrupted after fidelity seeds 0-4 and partial dot training. The same frozen source resumed completed test conditions without overwriting them and deterministically retrained incomplete dot conditions. It completed all ten conditions; inference from the ten saved best checkpoints reproduced the retained logits on both full splits.
* Validation accuracy above 90% did not transfer: the hybrid fidelity model averages 96.26% validation accuracy and 85.54% test accuracy. The earlier assertion that prevalence shift was the clear main cause was unsupported; reports now distinguish the observed gap from an unproven causal explanation.
* Preliminary threshold diagnostics inspected test-optimal cutoffs and the known test class counts. Those calculations are oracles, not deployable methods. Any >90% oracle values are explicitly excluded from valid results. The persisted calibration audit uses validation labels and unlabeled target predictions for planning, then test labels only for scoring.
* The fixed robust-training pilot selected AdamW over SAM by class-balanced validation NLL. Its quantum ensembles did not cross 90%: product 89.74%, entangled 89.10%. Both quantum maps have complete-test PennyLane verification, with every failed pilot and final condition retained.
* Frozen ImageNet features extracted from upsampled 28-pixel images improved validation losses but produced 86.70% test accuracy for both quantum ensembles. These results are preserved; better validation fit alone is not evidence that test generalization improves.
* Downloading official ResNet-18 weights was initially blocked by sandbox network permissions. The reviewed single-file download succeeded and its official SHA-256 prefix was checked. The native-224 download was slow; its partial prefix was retained and resumed with four bounded HTTP ranges. Assembly was accepted only after the published full-file MD5 matched. No experiment uses a partial or unverified dataset.
